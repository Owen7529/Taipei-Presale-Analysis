# 雙北市預售屋成交資料：八張圖表的分析重點

## 資料來源、研究期間與統計口徑

- 地區：臺北市、新北市。
- 交易日期：**2023/09/21～2026/09/20**（含首尾）。完整自然月：**2023/10～2026/08**。
- 來源：內政部預售屋實價登錄公開批次（分析採用 **16 份來源 ZIP**，逐批紀錄保存在本機 `data/source_inventory.csv`）。
- 房地成交樣本：**44,226 筆**；可比較單價：**44,079 筆**；可比較房地總價及房地建物面積：各 **44,134 筆**。
- 房地總價與面積使用現有清理程式已扣除**可明確拆分**車位部分的欄位；無法拆分者不納入該指標的比較。面積包含共有部分，不是室內使用面積。
- 成交筆數代表當次取得之官方**已揭露、且通過清理**的交易，不代表全部市場成交總量或建案件數。

## 圖表取捨原則

每張圖只回答一項核心問題：時間趨勢、行政區集中程度、行政區單價排名、房地總價與面積分布、單價離散程度。行政區圓環圖用「前八名＋其他」降低其他占比；對完整母體的計算與有效樣本仍保留在清理資料與統計表中。

為避免圖表主題重複，主要成果僅保留八項分析問題。三年成交總量、行政區年度熱力圖與 12 個月移動中位數不列入主要圖表；若有新的研究需求，可使用相同的已清理資料另外分析。

## 解讀限制

1. 本專案只進行描述性資料分析，不以單一圖表推論特定政策、市場供需或投資潛力。
2. 預售屋資料存在批次更正、解約更新及揭露延遲；不能把公開樣本數當作市場全部交易。
3. 三年不同期間的建案、地段、坪數與產品組成可能不同；單價比較不是房價指數。
4. 不從單價統計直接推算成交總價，也不將建物移轉面積等同於室內面積。
